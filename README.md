# Key-value Store written in Rust

This is a simple project to help me learn rust.

Here are the phases/goals (generated by Gemini)
1. Create a simple key-value store using a Rust struct and Hashmap (DONE)
2. Add a synchronous TCP server and parse simple command to expose the key-value store (IN PROGRESS) [phase-two-tcp-server](https://github.com/cubeguerrero/kv_store/tree/phase-two-tcp-server)
    To test, you'll need two terminal windows
    For the first one,
    ```
    $ cargo run
    ```

    Second window
    ```
    $ telnet localhost 8000
    ```
3. Start adding concurrency and basic multi-threading
4. Create a robust protocol and error handling
5. Asynchronouse I/O (Async and Await)
6. Advanced features & refinements (graceful shutdown, add observability)
